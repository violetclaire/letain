# Beauvette: August 1994

A self-contained interactive magazine app modeled on the visual language and
editorial voice of a mid-'90s American beauty glossy (design reference:
Allure, circa 1994 — Didone cover lines, clinical whitespace, red accents,
the brown-lipstick/Vamp/CK One/AHA moment).

No build step, no dependencies, no network calls. Open `index.html` in a
browser, or serve the folder statically:

```
npx serve allure-1994
```

Departments: Cover, Contents, Beauty Reporter, a feature ("The Brown Study"),
the interactive Makeover Counter, the Minimalist-or-Vamp quiz, the Beauty
Horoscope, and the Directory. A blow-in subscription card falls out when you
open the issue, as is tradition.
